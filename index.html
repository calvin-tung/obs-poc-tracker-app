How this tracker works

  1. Everyone opens the same web address and signs in with the team password.
  2. Every change saves to the shared tracker within a few seconds. Colleagues' changes appear on your screen within 20 seconds.
  3. If two people change the same task, both changes are kept when they touch different fields. For the same field, the later change wins.
  4. Tick Remember me to skip the password on your own laptop for 30 days. Use Sign out in the menu on shared machines.
  5. Download data gives a CSV for Excel. Upload data loads it back; rows match on ID.

Data is encrypted before it leaves your browser. Sign-ins are recorded with name, time and IP address for the tracker admin.

How to share updates through OneDrive

Best: live sync (Chrome or Edge, OneDrive folder synced to your laptop).

  1. In Finder or File Explorer, open the OneDrive folder and double-click the tracker so it opens in Chrome or Edge.
  2. Click Connect OneDrive file in the red bar and pick that same tracker file. Allow editing when asked. You do this once per laptop.
  3. From then on every change writes into the file within a few seconds, and OneDrive uploads it. Every 20 seconds the tracker checks the file for colleagues' changes and pulls them in.
  4. Next time you open the tracker, click the yellow Resume sync button once. The browser needs one click before it can write again.

Without live sync (Safari, Firefox, or opened from the OneDrive website):

  1. Download the tracker from OneDrive and open it in Chrome or Edge on a laptop. Phones can view it but are not reliable for saving.
  2. Click any task to update status, target date, actual done date or blocker. Edits autosave in this browser.
  3. Click Save tracker. The button shows how many changes are not yet saved into a file.
  4. In OneDrive, upload the new file and choose Replace. If your browser named it OBS-PoC-Tracker (1).html, rename it to OBS-PoC-Tracker.html first, or OneDrive keeps two files.

OneDrive conflict copy? If two laptops write at the same moment, OneDrive may keep a second file with a computer name added. Click Upload data and choose that file: the tracker merges it task by task. Then delete the copy.

Two editors? If someone uploaded a newer file while you had unsaved edits, the tracker merges them task by task when you open the new file. The most recent change to each task wins, and a banner tells you what happened.

Bulk edits in Excel: Download data, edit Status, Owner, Target date, Actual done or Blocker, then Upload data. Rows match on ID. Dates outside the PoC window are skipped and listed.

Always start from the latest file. Before you edit, open the newest tracker from OneDrive, not an old copy in Downloads. If you open a file that lacks changes you saved earlier, the tracker puts them back and tells you.

Late and early count working days against the original planned end date. Saves are ordered by each laptop's clock, so keep clocks on automatic time.
